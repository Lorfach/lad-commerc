# lad-commerce

Сайт компании ТОО «Лад Коммерц» (Алматы) — оптовые поставки кондитерских изделий.

## Стек

- Next.js 15 (App Router)
- React 19
- TypeScript

## Разработка

```bash
pnpm install
pnpm dev
```

Локальный сервер: `http://localhost:3000`.

## Сборка

```bash
pnpm build
pnpm start
```
