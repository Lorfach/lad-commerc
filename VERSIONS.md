# История версий и точки отката (Rollback Points)

В этом файле фиксируются контрольные версии проекта, чтобы в любой момент можно было быстро вернуться к рабочей версии до внесения масштабных изменений.

## 📌 Версия 3.2.1 (Исправление интерактивности Яндекс.Карт, выравнивания десктопного топбара и постоянной фиксации мобильного топбара)

- **Версия / Тег:** `v3.2-yandex-map-release`
- **Дата фиксации:** 10 ноября 2026 г.
- **Описание изменений:**
  1. **Исправление багов карты (`CoverageMap.tsx`):**
     - **Причина бага в прошлой версии:** виджет `yandex.kz/map-widget/v1` (iframe) при передаче нескольких меток в параметре `pt` через `~` принудительно масштабировал карту по крайним точкам всей области и полностью игнорировал параметры центра (`ll`) и зума (`z`), а `encodeURIComponent` ломал парсинг координат.
     - **Решение:** карта переведена на полноценный **Yandex Maps JavaScript API 2.1** (`ymaps.Map` + `ymaps.Placemark`) с двусторонней связью:
       - Установлены точные координаты здания склада **г. Алматы, ул. Черноморская, 12** (`43.284794, 76.935269`, Жетысуский р-н) по данным 2ГИС / Яндекс.Карт, а также точные координаты центров всех 8 районов Алматы и 7 населенных пунктов области.
       - Клик по любому чипу на сайте (`Склад`, `Алмалинский р-н`, `г. Талгар`, `г. Каскелен` и т.д.) плавно переносит камеру карты (`map.setCenter`) на выбранную точку с нужным масштабом, выделяет пин и открывает балун с описанием.
       - Клик по любой метке прямо на Яндекс.Карте синхронно выбирает соответствующий район/город на сайте и обновляет карточку описания справа.
  2. **Исправление выравнивания компьютерного топбара (`HeroSection.module.css`):**
     - Устранено расхождение внутренних отступов `padding: 0 32px` внутри `max-width: 1200px`, из-за которого шапка была уже верхней полоски и остальных секций на `64px`. Теперь `.topContainer`, `.headerNav` и `.heroContainer` выровнены по единой вертикальной сетке `1200px`.
     - Десктопная шапка переведена на трехколоночную сетку (`grid-template-columns: auto 1fr auto`): логотип строго слева, навигационное меню строго по центру (`justify-self: center`, без переноса строк), телефоны строго справа с табличным выравниванием цифр (`tabular-nums`) и бейджем `WhatsApp` слева от номера.
  3. **Постоянное закрепление мобильного топбара (`HeroSection.module.css`, `globals.css`):**
     - На мобильных и планшетах (`<= 1024px`) `.headerStrip` переведен с `position: sticky` (который переставал работать после прокрутки `HeroSection` и из-за `overflow-x: hidden` на `body`) на `position: fixed; top: 0; left: 0; right: 0; z-index: 95;` с компенсирующим `padding-top: 62px` у `.heroWrapper` и `scroll-padding-top: 76px` у `html`. Теперь топбар с кнопкой звонка и выпадающим меню `Разделы` закреплен наверху экрана на протяжении всей страницы.
- **Как откатиться на состояние ДО Яндекс.Карт:**
  ```bash
  git checkout v3.1-before-yandex-map
  # или по хешу коммита:
  git checkout 83f1ecb
  ```

- **Версия / Тег:** `v3.0-production-ready`
