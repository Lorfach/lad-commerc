# История версий и точки отката (Rollback Points)

В этом файле фиксируются контрольные версии проекта, чтобы в любой момент можно было быстро вернуться к рабочей версии до внесения масштабных изменений.

---

## 📌 Версия 2.3 (Выполнение /impeccable clarify и /impeccable distill)

- **Версия / Хеш коммита:** `a94041a`
- **Дата фиксации:** 10 ноября 2026 г.
- **Описание изменений:**
  - **Clarify (ясность языка и действий):**
    - Унифицированы все целевые кнопки по сайту: точный призыв к действию `«Написать в WhatsApp»` вместо абстрактного `«Перейти в WhatsApp»`.
    - Устранены расхождения в графике работы: единый режим склада и офиса `Пн – Пт: 09:00 – 18:00, Сб: 09:00 – 14:00 (Вс: выходной)` в блоках «О компании» и «Контакты».
    - Уточнены фильтры интерактивной карты: `Вся карта`, `Алматы (8 районов)`, `Алматинская область (7 направлений)`.
    - Тексты порядка работы переписаны в активном залоге без лишней воды.
  - **Distill (устранение визуального шума и дублирования):**
    - Из сайдбара интерактивной карты доставки удалена дублирующая карточка `factsCard` (ее тезисы полностью раскрыты в блоке склада), что позволило выровнять сайдбар по высоте карты без лишнего скролла.
    - Упрощена структура данных в `WarehouseLogistics.tsx`, устранены фрагментированные свойства и инлайн-стили.
    - Сжата и отточена формулировка блока коммерческих условий: конкретика для розницы и оптовиков без шаблонных фраз.

### Как откатиться к базовой версии:

```bash
# Вариант 1: Временно переключиться на базовую версию (detached HEAD)
git checkout v1.0-baseline
# или
git checkout 7724c31

# Вариант 2: Полный и безвозвратный откат ветки main к исходному состоянию
git reset --hard 7724c31
```
