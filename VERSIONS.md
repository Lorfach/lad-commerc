# История версий и точки отката (Rollback Points)

В этом файле фиксируются контрольные версии проекта, чтобы в любой момент можно было быстро вернуться к рабочей версии до внесения масштабных изменений.

---

## 📌 Базовая версия (Исходный лендинг)

- **Версия / Тег:** `v1.0-baseline`
- **Хеш коммита (исходный код лендинга):** `7724c31679d40ee77a4cdd854003ab3aba3daeb6` (`7724c31`)
- **Дата фиксации:** 20 октября 2026 г. / 10 ноября 2026 г.
- **Описание состояния:**
  - Полный исходный вариант одностраничного лендинга ТОО «Лад Коммерц».
  - Включает 7 базовых компонентов (`HeroSection`, `CategoryShowcase`, `AboutCompany`, `WarehouseLogistics`, `CollaborationSteps`, `ContactsFooter`, `InquiryFormModal`, `MobileStickyBar`).
  - Старое позиционирование (упоминания «опт», форма запроса оптового прайс-листа, городской телефон).

### Как откатиться к этой версии:

```bash
# Вариант 1: Временно переключиться и посмотреть базовую версию (detached HEAD)
git checkout v1.0-baseline
# или
git checkout 7724c31

# Вариант 2: Полный и безвозвратный откат ветки main к этому состоянию
git reset --hard 7724c31
```
