# История версий и точки отката (Rollback Points)

В этом файле фиксируются контрольные версии проекта, чтобы в любой момент можно было быстро вернуться к рабочей версии до внесения масштабных изменений.

---

## 📌 Версия 2.0 (Дистрибьюция 3 заводов, карта охвата, компактный первый экран)

- **Версия / Тег:** `v2.0-distribution-release`
- **Дата фиксации:** 10 ноября 2026 г.
- **Описание изменений:**
  - Полный переход с формулировок «опт» на «официальная дистрибьюция».
  - Полный отказ от цен и упоминаний прайс-листов: внедрен персональный расчет коммерческих условий (для розницы и оптовиков).
  - Компактный первый экран (Hero) с 3 быстрыми навигационными кнопками: «Ассортимент 3 заводов», «Местоположение и карта», «Контакты и склад».
  - Новый компонент `FactoryPartners.tsx`: 3 российских завода (КФ «Алёшина», «Черногорский Кондитер», «Томский Кондитер») с их флагманскими позициями и форматами фасовок.
  - Новый компонент `CoverageMap.tsx`: интерактивная визуальная карта покрытия с центральным складом на Черноморской, 12 и звездочками-точками по всем районам Алматы и Алматинской области (Талгар, Каскелен, Конаев, Есик, Шелек и др.).
  - Полное удаление городского телефона `+7 (727) 383-09-06`; установлены два сотовых номера: Kcell (`+7 (701) 713-97-38`) и Tele2 / WhatsApp (`+7 (707) 823-34-22`).
  - Обновление модального окна `InquiryFormModal` и мобильной плашки `MobileStickyBar`.

### Как откатиться к базовой версии:

```bash
# Вариант 1: Временно переключиться на базовую версию (detached HEAD)
git checkout v1.0-baseline
# или
git checkout 7724c31

# Вариант 2: Полный и безвозвратный откат ветки main к исходному состоянию
git reset --hard 7724c31
```
